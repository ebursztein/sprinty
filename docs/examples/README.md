# Try Sprinty on a real project

Pick a project, paste its starting prompt into your agent, and follow the sprint in the dashboard. Each example goes from a goal to a concrete result rather than demonstrating isolated tool calls.

| Example | What you finish | What Sprinty helps coordinate |
| --- | --- | --- |
| [Launch a product website](website-launch.md) | A reviewed website and launch checklist | Research, design, content, build, and review |
| [Prepare a research brief](research-brief.md) | A sourced brief with findings and open questions | Evidence gathering, synthesis, and review across sessions |
| [Work with several agents](parallel-agents.md) | A website launch pack with coordinated contributions | Separate assignments, dependencies, progress, and handovers |

These are workflows to try, not claims of customer results. You need a Git-backed project folder and a connected Sprinty server. Use the [setup prompt](https://ebursztein.github.io/sprinty/agent-start.txt) if setup is not complete. The [45-second walkthrough](https://ebursztein.github.io/sprinty/demo.html) shows an illustrative website project.

A useful first result: one task claimed, a meaningful deliverable saved, a real check recorded, and the work recoverable in another session. A whole sprint need not finish on your first visit.
